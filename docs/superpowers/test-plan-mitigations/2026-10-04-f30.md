# F30 — Auto Layout off does not keep node positions

Walk: `2acbc87a` 2026-10-04
Area: flow designer, Layout Test
Reproduced by: TEST-PLAN F30. Auto Layout was turned off
and its PUT landed before the rename. Panel B became
Panel B F30, the flow PUT landed, and after
flows/index.html and back the switch was still off.
The name, 18 nodes, 25 edges, and 0-attribute labels
persisted. Every transform changed. Draft
translate(-958.5, -747) came back
translate(-964.5, -512.78).

## Seen

With Auto Layout off, a saved rename survived the
round trip and the node and edge counts survived.
The stored transforms did not. Boot laid the graph
out again anyway.

## Expected

Positions persist when Auto Layout is off. Turn it
off, wait for the flow PUT, then leave and return.
A re-layout is the on-boot behavior only when Auto
Layout is on.

## Not tried

No second flow. No reload without a rename. No
comparison of the saved message-pair positions with
the positions the designer paints on boot.
